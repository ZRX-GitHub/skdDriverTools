# 三颗豆 功能介绍

> 文档对应版本：**v1.4.27**
> 适用平台：Windows 10 / 11（x64），Python 3.13 + PySide6 6.9.3
> 项目定位：**多品牌设备的轻量状态面板与参数管理工具**，常驻托盘、无需浏览器授权、不依赖厂商网页驱动。

---

## 1. 这是什么

三颗豆是一个固定在桌面右下角的迷你玻璃面板，通过 **Windows 原生 HID 接口直接与设备通信**，实时显示：

- 电量与充电状态（无线设备）
- 品牌 / 型号 / 固件 / 序列号后六位
- 当前 DPI 与档位（第几档 / 共几档）
- 回报率（Hz）及对应的延迟挡位
- 连接方式（2.4G 无线 / USB 有线、接收器型号）

对支持写命令的设备，还能**直接在面板里改 DPI、管理 DPI 档位、切换回报率挡位**；对不支持的设备，界面会明确写出「谁在管这件事」，不给点了没反应的假按钮。

程序随 Windows 启动、缩到托盘后仍在后台读数；插上多台设备时，点标题即可展开设备清单切换查看。

> 原始声明（见 `src/setup_core.py` 的 `DESCRIPTION` 与 exe 版本信息）：
> “本软件适用不同品牌鼠标驱动的管理，例如DPI、刷新率、电量的管理。**本软件已开源，禁止私自商用**。”

## 2. 特性速览

| 类别 | 能力 | 说明 |

## 3. 界面导览

### 3.1 主窗口（396 × 470，固定尺寸、不可拖动）

```
┌──────────────────────────────────────────────┐
│ ● 三颗豆驱动管理 · 5台设备 · 已连接   [齿轮] [×]│  ← 状态行（可点开设备清单）
│ ● CROCIRIS X7 Ultra Max                  ⌄   │  ← 品牌（主色）+ 型号
│              ╭───────────╮                    │
│              │   57%     │                    │  ← 电量环（环形进度 + 中心文字）
│              ╰───────────╯                    │
│   ┌────────┐ ┌────────┐ ┌────────┐          │
│   │ 灵敏度 │ │ 回报率 │ │ 连接   │          │  ← 三张信息卡
│   │ 650DPI │ │ 1000Hz │ │ 2.4G   │          │
│   └────────┘ └────────┘ └────────┘          │
│   固件 1.02 · SN 123456 · 每 2 秒自动刷新     │  ← 说明行
│   [ 打开官方网页驱动 ]                  ( ⟳ ) │  ← 主按钮 + 刷新圆钮
└──────────────────────────────────────────────┘
```

- **状态行**：`三颗豆驱动管理 · N台设备 · 已连接`。软件名用品牌蓝、设备数用次级灰、连接状态用绿色；左侧呼吸点与状态色呼应。灰色悬停底衬那一块既是点击热区，也是显示手型光标的唯一范围。
- **型号行**：绿色状态点 + 品牌（DemiBold）+ 型号；品牌是定语，空间不够时先省略品牌、保证型号完整。
- **电量环**：环形进度 + 中心百分比；充电时整环转绿并显示闪电与流动光带。**纯有线设备**画满 100% 绿环，中心写绿色「USB供电」，不写百分比（有线鼠标没有电池，写数字等于编数据）。
- **三张信息卡**：灵敏度 / 回报率 / 连接。卡片默认纯展示，悬停**不**变手型、不亮高亮；只有当前设备可写时，点击卡片才进入编辑模块，右侧下拉按钮才弹挡位面板。
- **说明行**：固件、序列号后六位、自动刷新周期；没有固件/序列号的无通道设备改显示 `VID:PID XXXX:XXXX`。
- **主按钮**：按设备形态变成「打开官方网页驱动」/「打开官方软件驱动」/「无官方软件 · 按键调节」（禁用）/「重新扫描」（未连接时）。

### 3.2 设备清单弹窗

点状态行展开，是独立的无边框浮层（`Qt.Tool`，不是 `QMenu`、也不是主窗口子控件），不会抢鼠标 grab，也不会被主窗口重绘糊掉。

- 每行：左侧绿色对勾（当前设备）+ **品类图标**（鼠标 / 键盘 / 耳机，12px 线稿）+ 品牌（主色）+ 型号（次级灰）+ 右侧电量。
- 电量文字规则：
  - 纯有线 → 绿色「USB供电」
  - 无线有读数 → 按阈值分色的百分比（≤阈值红 / 阈值+1~+15 橙 / 更高绿）
  - 无线但读不到 → 灰字「无法读取」
  - 未连接的设备不进清单
- **键盘 / 耳机行 `switchable=False`**：不亮悬停底衬、不给手型、点击不发切换信号，也不收起菜单。
- 头部「N台设备」由 `main.device_menu_rows()` 统一提供行数据，与弹窗行数**始终一致**（含配件）。

### 3.3 设置浮层

右上角齿轮打开，312 × 386 的独立浮层卡片，150ms 淡入 + 6px 滑入动画。整行可点（点标题等同于点右侧开关），命中范围严格等于胶囊矩形。

| 选项 | 说明 |
| --- | --- |
| 开机自动启动 | 写 `HKCU\...\Run` |
| 窗口置顶 | 走 Win32 `SetWindowPos`，不重建窗口（避免收掉浮层） |
| 关闭时最小化到托盘 | 当前固定为开启；× 缩到托盘而非退出 |
| 主题 | 系统 / 浅色 / 深色（系统模式每 1.5 秒检查一次） |
| 语言 | 中文 / English，即时生效 |
| 低电量提醒 | 通知总开关 |
| 提醒阈值 | 10% / 15% / 20% / 30%（配置可指定 5–50 任意值） |
| 电量图例 | 红 / 橙 / 绿三段，跟着阈值实时变化 |

**纯有线设备接线时**：低电量提醒、提醒阈值两行与底部图例整体置灰禁用，表示「这台没得调」。

### 3.4 托盘与右键菜单

- 单击/双击托盘图标：显示或隐藏面板；悬停显示「型号 · 电量」（有线为「型号 · USB 有线」）。
- 托盘右键：显示窗口 / 立即刷新 / 打开网页驱动 / 开机自动启动 / 设置… / 退出。
- 窗口右键：立即刷新 / 打开网页驱动 / 置顶 / 设置 / 最小化到托盘 / 退出。
- 在窗口外点一下自动收回托盘；点窗口自身、设置浮层、托盘小窗不会误收。
- 通知用 `Crociris.MouseGlass.1` 这个 AppUserModelID 注册，显示的是本软件名与图标。

### 3.5 安装器

- 双语界面 + 面板内语言分段控件；首次安装跟随系统 UI 语言（非中/英回退中文），升级沿用上次选择。
- 默认装到 `%LOCALAPPDATA%\Programs\skdDriver`，**不需要管理员权限**；自选目录时程序本体一律落在所选目录下的 `skdDriver` 子文件夹（选 `D:\Apps` → `D:\Apps\skdDriver`）。
- 创建开始菜单/桌面快捷方式、写自启动项、写 `HKCU\...\Uninstall\MouseGlass` 卸载项。
- 命令行：`skd-setup-<版本>.exe --silent --dir "D:\Apps" --lang zh`。
- 安装目录含 `MouseGlass.exe`、`uninstall.exe`、`app.ico`、`_internal\`（PyInstaller onedir 运行时，**不可删、不可改名**）。

## 5. 核心功能细节

### 5.1 数据采集与休眠

- 每台设备一个后台线程，默认 2 秒一轮，通过 `snapshot()` 返回线程安全的 `MouseInfo` 快照；主窗口 350ms 定时同步 UI。
- 2.4G 鼠标静止后接收器返回全 0 帧 → 判定「休眠中」，**保留上次读数**并降频到约 5 秒，移动鼠标后 1–5 秒恢复实时。
- 上次读数写入 `%APPDATA%\MouseGlass\config.json` 的 `cache`，重启后立刻可见；`cache` 按设备分开存（`crociris` / `logitech` / `basic` 各一份），避免串台。
- 当前设备拔线时临时让位给另一台在线设备，选择本身不丢，插回来自动回到原来那台。

### 5.2 电量与低电量提醒

- 配色三档：≤阈值红 / 阈值+1~阈值+15 橙 / 更高绿；电量环、设备清单百分比、设置页图例共用 `theme.battery_color()`。
- 通知文案示例：「XXX 电量 8%，已低于 15%，请及时充电」；继续下降 3% 以上再提醒，未处理每 30 分钟重提；插线或电量回升自动重置。
- 纯有线设备不发低电量通知，托盘提示写「型号 · USB 有线」。

### 5.3 DPI 与档位编辑

- **可写设备**点灵敏度卡进入编辑模块：步进器输入（按 `DeviceCaps.align_dpi()` 对齐合法档位）、右侧下拉选挡位、挡位管理弹窗（增删档位，最多 `MAX_DPI_STAGES`）。
- 范围来自型号规格表（`devcaps.DPI_SPECS` / `LOGITECH_SPECS`），再用设备真实档位表撑开边界，避免把设备里已有的合法档判成越界。
- 罗技「档位」必须跟 G HUB 里配的档一致：优先只读解析 `%LOCALAPPDATA%\LGHUB\settings.db`，其次板载 profile，都拿不到就显示「实时读取」，**绝不拿 511 档传感器能力表凑数**。
- 档位显示与数值同帧刷新（`_calibrate_stage()` / `_level_for()`），不会出现「数字先变、档位后变」。

### 5.4 回报率

- 显示 125 / 250 / 500 / 1000 / 2000 / 4000 / 8000 Hz，下方按 `1000/Hz` 标延迟挡位：125–250 高延迟 / 500–1000 中延迟 / 2000–8000 低延迟。
- 可写时点卡片进入编辑模块，点下拉按钮弹出挡位面板选挡位；**不手打数字**。
- 不可写时 `set_pick_values([])`，卡片不可点、不弹窗，范围提示也不显示。

### 5.5 「不支持」时的统一呈现（重要）

软件不伪造数据、不给点了没反应的控件。判定全在 `_update_edit_caps()` / `_apply_info()` / `_apply_driver()`：

| 场景 | 卡片右上角常驻角标 | 卡片副标题 | 底部主按钮 | 设备清单右侧 |
| --- | --- | --- | --- | --- |
| 数值由 G HUB 管（罗技只读） | 「由 G HUB 支持」 | 正常读数 | 打开官方软件驱动 | 百分比 / USB供电 |
| 数值由其它官方软件管 | 「由 官方软件 支持」 | 正常读数 | 打开官方网页驱动 | 百分比 / USB供电 |
| 设备没有软件通道（狼途这类） | 「由 按键 支持」→ 渲染为「按键调节」 | 「无法读取」 | 禁用 +「无官方软件 · 按键调节」 | 「USB供电」 |
| 配件（键盘 / 耳机） | 不进主界面 | — | — | 「USB供电」/「无法读取」+ 不可切换 |

角标是**常驻**的只读标识，只在不支持编辑的模块出现；有角标时标题自动缩字号，角标自身 8px→7px 降级，绝不挤压标题。

### 5.6 驱动入口

`src/driver.py` 按设备分三种形态：

- `WEB`（CROCIRIS）→ 浏览器打开网页驱动地址（可在 `config.json` 的 `hub_url` 改）。
- `SOFTWARE`（罗技）→ 找 `lghub.exe`（常见目录 + 卸载注册表项，结果缓存），以 `DETACHED_PROCESS` 拉起；没装则打开官网下载页。
- `NONE`（无官方软件）→ 按钮禁用，鼠标悬停提示「这台鼠标没有官方软件，DPI 和回报率用鼠标上的按键调节」，点击不做任何事。

### 5.7 外观与语言

- 全控件自绘：液态玻璃（折射底图 → 乳白本体 → 折光带 → 镜面高光 → 内缘阴影 → 描边 → 顶缘 1px 高光），所有渐变只沿 y 轴，避免「左亮右暗」斜切感；深色模式跳过顶部打光，做成哑光玻璃。
- 主题切换时设置浮层的折射底图从**主窗口背景缓存**重建，不会把浮层自己拍进去。
- i18n 以中文原文为键：`i18n.T("设置")`，漏条目原样返回中文（绝不显示空白）；画出来的文字在 `paintEvent` 现取 `T()`，存进控件的文字在切语言时显式 retranslate。
- 安装器、主程序、托盘、通知、设置、设备清单、错误提示全部双语。

### 5.8 安装、配置与卸载

| 项 | 位置 / 命令 |
| --- | --- |
| 默认安装目录 | `%LOCALAPPDATA%\Programs\skdDriver` |
| 配置 | `%APPDATA%\MouseGlass\config.json`（原子写入；含主题、语言、阈值、设备选择、缓存、窗口位置） |
| 日志 | `%APPDATA%\MouseGlass\logs\app.log` |
| 自启动 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |
| 卸载项 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\MouseGlass` |
| 卸载 | 安装目录 `uninstall.exe`（`/quiet` 静默）／系统「已安装的应用」／`MouseGlass.exe --uninstall` |

卸载会清掉快捷方式、自启动项、注册表项与配置目录；`uninstall.exe` 自带运行时，不依赖 `_internal`。

## 6. 技术实现概览

| 模块 | 职责 |
| --- | --- |
| `src/main.py` | 主窗口、UI 同步、编辑交互、托盘、设备清单、低电量调度 |
| `src/widgets.py` | 全自绘控件：信息卡、电量环、设备菜单、设置胶囊、开关/分段、液态玻璃绘制 |
| `src/monitor.py` | `MouseInfo` / `DeviceCaps` 消费者、三路采集器、`DeviceHub` 统一对外接口 |
| `src/protocol.py` | CROCIRIS 私有帧：`0xAA/0x55` 打包、状态帧/设备信息帧/档位表解析、延迟挡位 |
| `src/logitech.py` / `src/ghub.py` | HID++ 2.0 特征读写、设备名/DPI/回报率/电量、G HUB 配置解析 |
| `src/hid_win.py` | Windows HID 枚举、`HidCollection`、设备打开/读写/在位检测 |
| `src/devcaps.py` | 可调能力对象 `DeviceCaps`：范围、步进、挡位、可写性、对齐与提示文案 |
| `src/hidbrands.py` | VID/PID → 品牌 / 型号 / 品类表（无协议设备的「认人」入口） |
| `src/accessories.py` | 键盘 / 耳机枚举与「只展示」行构造，3 秒后台轮询 |
| `src/driver.py` | 按品牌分派网页驱动 / 客户端软件 / 无官方软件 |
| `src/i18n.py` | 中文原文为键的双语表与格式化 helper |
| `src/theme.py` / `wineffects.py` | 调色板、电量配色、Win32 托盘小窗可见边框计算 |
| `src/config.py` / `applog.py` / `notify.py` / `autostart.py` | 配置持久化、日志、系统通知、自启动 |
| `src/setup_core.py` / `installer.py` / `uninstall*.py` | 安装、卸载、注册表、快捷方式 |
| `build.py` | 图标渲染、版本信息、PyInstaller 打包、版本号自增 |

线程模型：每个采集器一条 daemon 线程；配件扫描独立线程（HID 枚举实测约 240ms，不能卡在点击标题那一下）；UI 只在主线程通过快照同步。

配置默认值：`poll_interval=2.0`、`low_battery_threshold=15`、`close_to_tray=True`、`device="crociris"`、`language="zh"`。

## 8. 已知边界

- **只支持 Windows**：HID 枚举、托盘小窗、通知、注册表都走 Win32 API。
- **不测量实际轮询率**：回报率显示的是设备上报/写入的挡位，不是用 Raw Input 数出来的实测 Hz。
- **配件只读**：键盘 / 耳机只在设备清单里出现，不提供背光、宏、音量等控制。
- **认不出的设备不显示**：品牌表没收录的 VID 直接忽略——把杂牌标成某品牌比不显示更糟。
- **一个接收器配对多只鼠标**：目前显示先探到的那一只。
- **私有协议范围按型号表兜底**：CROCIRIS 私有协议没有「读传感器可调范围」的命令，范围来自官方参数页 + 设备真实档位表取并集。
- **多显示器**：窗口只贴主屏右下角；显示器增删/主屏变化时会重新贴边。
